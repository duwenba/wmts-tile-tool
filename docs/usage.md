# 使用实例图

本文用 Mermaid 流程图说明 WMTS 瓦片工作台（`uv run python -m wmts.server`）的典型使用路径。
界面为**地图优先工作台**：左边是地图，右边是「数据源与范围 → 任务与进度 → 结果与导出」流程面板，
缓存与日志收在底部抽屉里。

---

## 1. 端到端主流程（首次使用）

```mermaid
flowchart TD
    A["启动服务<br/>uv run python -m wmts.server"] --> B["打开浏览器工作台"]
    B --> C{"地图能加载瓦片？"}
    C -- "否，提示鉴权失效" --> D["浏览器登录数据源<br/>复制 Cookie"]
    D --> E["右侧面板①：粘贴 Cookie → 保存配置"]
    E --> B
    C -- "是" --> F["面板①：确认图层 Layer / 矩阵集 / EPSG"]
    F --> G["地图：滚轮缩放到目标级别<br/>拖拽平移到目标区域"]
    G --> H{"怎么确定下载范围？"}
    H -- "框选" --> I["按 S 切到框选工具<br/>拖拽画框 → 选区条显示片数/体积"]
    H -- "手填" --> J["面板①展开下载范围<br/>填列/行起止"]
    H -- "整个图层" --> K["面板①：填入整个图层"]
    H -- "当前视图" --> L["面板①：用当前视图"]
    I --> M["选区条：应用为下载范围"]
    J --> M
    K --> M
    L --> M
    M --> N["面板②：一键执行全部<br/>下载 50% → 拼接 40% → 地理标签 10%"]
    N --> O["地图实时着色：绿=已下载 红=损坏 灰=待处理"]
    O --> P["面板③：结果与导出<br/>下载 GeoTIFF"]
    P --> Q["用 QGIS / GDAL 按真实经纬度打开"]
```

> 说明：`一键执行全部` 会按配置里的 `auto_geo` 决定是否在拼接后自动附加地理标签。

## 2. 场景 A：只下载一小块区域

```mermaid
flowchart LR
    A["地图缩放到 Level 16"] --> B["按 S 框选目标小区块"]
    B --> C["选区条：级别 16，N 列 × M 行 = X 片 · 约 Y MB"]
    C --> D["点『应用为下载范围』"]
    D --> E["面板②：仅下载"]
    E --> F["面板③：仅拼接 → 仅地理标签<br/>或直接一键执行全部"]
    F --> G["下载 GeoTIFF"]
```

要点：框选结果只落在**当前地图级别**上；若想换级别，先切级别再框选，或在面板①手改级别。

## 3. 场景 B：下载中断后续传 / 重试失败瓦片

```mermaid
flowchart TD
    A["下载中：关闭页面 / 点停止 / 网络中断"] --> B["瓦片已落盘，进度写入 download_progress.json"]
    B --> C["重新打开工作台"]
    C --> D["面板②下载进度块显示：断点进度 N 片 · 失败列表 M 片"]
    D --> E{"失败列表为空？"}
    E -- "否" --> F["点『重试失败瓦片』"]
    E -- "是" --> G["直接点『仅下载』继续"]
    F --> H["下载器跳过已完成瓦片，只补缺失与失败"]
    G --> H
    H --> I["完成后自动清理进度文件"]
```

要点：断点续传不需要任何额外操作——重跑下载即可；已下载的瓦片会在地图上显示为绿色。

---

## 4. 场景 C：切换图层

```mermaid
flowchart TD
    A["面板①：修改图层 Layer"] --> B["保存配置"]
    B --> C["重新拉取图层元数据<br/>（在线，首次后缓存到 layer_meta/）"]
    C --> D["地图自动缩放到新图层范围"]
    D --> E{"缓存里有旧图层的瓦片？"}
    E -- "是" --> F["底部『缓存管理』抽屉<br/>点『迁移旧结构』归入当前图层"]
    E -- "否" --> G["直接框选 / 下载新图层"]
    F --> G
```

要点：缓存按图层分层（`tiles/{layer}/{matrix}/{row}/{col}.png`），不同图层同坐标互不覆盖；
状态网格/统计只反映当前图层。

---

## 5. 场景 D：单瓦片预览并保存到缓存

```mermaid
flowchart LR
    A["在地图上点击任意瓦片"] --> B["右上角弹出气泡"]
    B --> C["显示缩略图 + 来源（本地/网络）+ 经纬度范围"]
    C --> D{"来源是网络？"}
    D -- "是" --> E["点『加入缓存』落盘"]
    D -- "否（已在本地）" --> F["按钮置灰，无需保存"]
    E --> G["地图上该瓦片变为已下载（绿色）"]
    C --> H["点『放大到此瓦片』把视图居中到该瓦片"]
```

## 6. 任务状态机（同一时刻仅一个任务）

```mermaid
stateDiagram-v2
    state "空闲" as Idle
    state "运行中" as Running
    state "完成" as Done
    state "失败" as Failed
    state "已取消" as Cancelled

    [*] --> Idle
    Idle --> Running: 点下载 / 拼接 / 地理标签 / 一键执行全部
    Running --> Running: progress 事件（阶段 + 百分比 + 瓦片着色）
    Running --> Done: done
    Running --> Failed: error（鉴权失效时弹出顶部红色横幅）
    Running --> Cancelled: 点停止 / cancel
    Done --> Idle
    Failed --> Idle
    Cancelled --> Idle
    Idle --> Idle: 再次启动（仍有任务占用时返回 409）
```

> 约定：占用期间 `POST /api/tasks` 返回 `409`；进度为单向 SSE，事件带自增 `seq`，
> 先回放缓冲再接实时流，刷新页面后会自动重新接入进行中的任务。
